# dotaanalyst.client

Front-end React 19 + Vite do DotaAnalyst. Veja o [README do projeto](../README.md).

- `npm run dev` — Vite em `https://localhost:59438` (as rotas `/api` vão para a API em `https://localhost:7208`).
- `npm run lint` / `npm run build`.
- Chamadas à API em `src/api/`; sessão em `src/auth/`; página de análise em `src/analysis/`.
